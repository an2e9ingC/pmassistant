## 1. 产品概述

PMA（Project Management Assistant）是一个**只读聚合仪表盘**，从禅道、GitLab、SVN 自动拉取数据，为多项目、多产品管理提供统一视图。

```
禅道 REST API ──┐
GitLab API ──────┼── 自动同步 ──► SQLite 缓存 ──► Web 仪表盘
SVN 文件服务器 ──┘
```

**核心原则**: 只读访问所有数据源，绝不回写。本地 SQLite 缓存减少对禅道/GitLab 的 API 压力。

### 3.2 已知限制

| 限制 | 说明 |
|------|------|
| 单文件 SQLite | 并发写入性能受限（~50 用户），database is locked 偶尔出现 |
| 全量同步 | 每次同步拉全量数据，大数据量时耗时较长 |
| 无 SSO | 未集成禅道 SSO，需单独 PMA 账号 |
| 无 WebSocket | 前端通过轮询（3s）获取同步进度，非实时推送 |
| Python 3.8 | 当前运行在 Python 3.8（EOL），建议升级到 3.10+ |
| 明文 HTTP | 部分内网数据源使用 http://，未强制 HTTPS |

## 5. 快速开始

### 5.1 环境要求

- Python 3.9+
- 可访问禅道服务器 `192.168.0.124:8800`

### 5.2 安装运行

```bash
# 1. 克隆仓库
git clone <repo-url> pma && cd pma

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置
cp .env.example .env
# 编辑 .env 填写禅道账号

# 4. 启动
./server.sh start -p 8000

# 5. 访问
open http://<服务器IP>:8000
```

### 5.3 默认账号
